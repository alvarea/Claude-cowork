# Claude-cowork

Skills y automatizaciones de Cowork con Claude organizadas por proyecto.

## Proyectos

### vacaciones-asturias-2026

Ver `vacaciones-asturias-2026/README.md` para descripción detallada de cada skill.

**busqueda-alojamiento-asturias** — Búsqueda diaria de alojamiento en Booking.com
**plan-excursiones** — Genera la web HTML del plan de viaje (7 tabs, rutas Maps, reservas)

## Uso
Ejecutar desde Terminal:
  bash skill_agente_vacaciones_to_github.ssh   # sube skill de búsqueda
  bash plan_excursiones_to_github.ssh           # sube skill del plan de viaje + README
