# Claude-cowork

Skills y automatizaciones de Cowork con Claude organizadas por proyecto.

## Proyectos

### vacaciones-asturias-2026
Agente de búsqueda diaria de alojamiento en Asturias para agosto 2026.
- Booking.com · 5 zonas · filtro A-8 · Gmail · Google Drive
- Incluye referencia de casa ya reservada en Airbnb (Vibaño, Llanes)

## Instalación de un skill
Abre el fichero `.skill` desde la app Cowork → "Save skill".
