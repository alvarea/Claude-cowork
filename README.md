# Claude-cowork

Skills y automatizaciones de Cowork con Claude organizadas por proyecto.

## Proyectos

### vacaciones-asturias-2026

**busqueda-alojamiento-asturias**
Agente de búsqueda diaria de alojamiento en Asturias para agosto 2026.
- Booking.com · 5 zonas · filtro A-8 · Gmail · Google Drive
- Reserva fija: El Solsuco Booking (Villaviciosa)

**plan-excursiones**
Genera la web HTML del plan de viaje a Asturias 2026 (Plan_Viaje_Asturias_2026.html).
- 7 tabs CSS-only (sin JavaScript, compatible Quick Look iCloud)
- Rutas Google Maps por día + rutas Sevilla ↔ Asturias
- Badges de estado por día (Cerrado / Por cerrar)
- 3 reservas confirmadas: VivePicos 4x4, La Galana, ALSA Lagos
- NO genera PDF — solo HTML interactivo

## Uso
Ejecutar desde Terminal:
  bash skill_agente_vacaciones_to_github.ssh   # sube skill de búsqueda
  bash plan_excursiones_to_github.ssh           # sube skill del plan de viaje
